# Co-Pal Café: Grab-Style Merchant Menu & Stock Management System

## Project Description
Co-Pal Café is a merchant-facing food and inventory management portal inspired by on-demand delivery platforms like Grab. The system allows café managers and administrators to maintain their live digital menu, control item pricing, monitor available stock levels in real time, and remove discontinued food or beverage offerings.

## Functional Requirements
- REQ-1 (Create): The system shall allow an administrator to add a new food or beverage item to the café menu by specifying its name, category, unit price, and starting stock quantity, enforcing validation on all submitted fields.
- REQ-2 (Read): The system shall display the entire active menu catalog in a formatted table showing item ID, name, category, price, and current stock status, with quick action links to edit or delete each item.
- REQ-3 (Update): The system shall allow an administrator to modify an existing item's details (such as updating price or replenishing stock) using a pre-populated edit form, preserving the item ID and validating changes upon submission.
- REQ-4 (Delete): The system shall allow an administrator to remove a food or beverage item from the menu catalog by its unique ID.
